# ML-competition
Nyc-Taxi-Trip Duration.

Это папка с jyuter-notebook, в котором представлено решение очень давнего соревнования на Kaggle про предсказание продолжительности поездки такси, весь feature engeneering, а также обучение моделей. Общий пайплайн в последних ячейках ноутбука NycTaxiTrip. В ноутбуке best_models находится лучший пайплайн обучения для решения
этой задачи, критерий проверки - MAE кросс-валидация на train части.
